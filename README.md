# Alemty.eth 1.0
Identidad Digital Descentralizada Web personal Ethereum ENS, desarrollado con HTML, CSS, JS y JSON en Visual Studio Code con Microsoft 365 Copilot Empresa sobre Windows 11 Pro 25H2. Sitio desplegado en IPFS, respaldado por nodo propio y pineado en Pinata, con acceso mediante CID enlazado a ENS.
